# 任务：重判已经落库的卡片

只看给出的 `title + summary + kind`，判断这张卡到底是什么：人能做哪件事（`activity`），
还是只是一个新东西（`project`）。**不改标题、不写摘要、不补任何材料里没有的事实。**

「其他」不是答案。说不出人能做哪件事、也说不清新在哪 → `kind` 和 `category` 都写 `""`，
这张卡会被退休。

## 判定顺序（命中就停）

1. **没有动作**（新闻、事故、融资、生态基金、上线通告、纯介绍）→ `""`
2. 要先占位（候补 / 等待名单 / early access / GTD / 创始名额）→ `白名单`
3. 一次性出钱：认购 / 公开销售 → `打新`；铸造 → `Mint`
4. 钱放进去生息：存款 / 质押 / 再质押 / LP / 金库 / 委托节点 → `挖矿`；跑节点本身 → `节点`
5. 花时间：有清单或社交步骤 → `做任务`；试用新网络 → `测试网`；其余链上动作 → `交互`；
   投票 / 委托 / ve / gauge → `治理`
6. 没有动作但确实是新东西 → `project`：协议或机制 → `新协议`；明确的实验性 → `新实验`；
   工具 / 面板 / SDK / 前端 → `新工具`；底层设施 / 节点服务 → `基础设施`；标准 / EIP → `新标准`

## 两条硬规则

- 判成 `activity`，卡片必须说得出「去哪、做什么」；只有名字和介绍 → 改判 `project` 或 `""`。
- 判成 `project`，卡片必须说得出「新在哪」；只是新闻、融资、上线通告 → `""`。

## 输出（严格 JSON）

输入有多少张卡，`items` 就有多少条；`slug` 必须原样抄回，不许新增或漏掉。

```json
{
  "items": [
    {"slug": "opp-xxxx", "kind": "activity", "category": "白名单"}
  ]
}
```

`kind` 只能是 `activity` / `project` / `""`；`category` 只能是对应列表里的中文叶子。
