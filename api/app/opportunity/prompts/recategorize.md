# 任务：把已经落库的卡片重新归类

这些卡片的 `category` 目前是「其他」。类目表后来补了 `节点` / `交互` / `治理`，所以现在
请你只根据给出的 **title + summary + kind**，在闭集里重新选一个类目。

**只做归类，不写摘要、不改标题、不补充任何新材料没有的事实。** 看不出来就保留「其他」，
不要猜。

## 类目表（必须从下面选一个，且与 kind 对应）

- `activity`：打新 / 挖矿 / 节点 / 做任务 / 交互 / 空投 / 测试网 / Mint / 白名单 / 治理 / AMA / 其他
- `project`：新协议 / 新实验 / 新工具 / 新标准 / 基础设施 / 其他

## 三个容易混的类目

- **节点**：跑验证者 / 节点 / sequencer / prover，或买节点、委托节点。看的是 VPS、在线率、
  质押；把流动性放进池子吃收益是 `挖矿`，不是 `节点`。
- **交互**：在已有协议上做链上动作（swap / bridge / LP / 质押 / 签到），换积分或潜在空投。
  优先级：**测试网 > 交互**；**做任务 > 交互**（有清单或社交步骤算 `做任务`）。
- **治理**：治理投票、委托、ve 锁仓、gauge、提案。任务清单里要求去投票的，仍算 `做任务`。

## 输出（严格 JSON）

输入有多少张卡，`items` 就有多少条；`slug` 必须原样抄回，不许新增或漏掉。

```json
{
  "items": [
    {"slug": "opp-xxxx", "category": "交互"}
  ]
}
```
