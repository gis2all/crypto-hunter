# 挖链

`search/` 只干一件事：找到这个项目的官方入口。`base`（命中与 URL 归一）/ `identify`（读页面定 tier）/ `discover`（搜索与互证）/ `harvest` / `engines/xsearch`。搜索不走模型、不花 token。

## 链下调研（挖链部分）

搜索产出候选，`identify` 读页面定 tier，两者都只交出链接。写词条与 LLM 客户端那几节在 `api/app/report/README.md` · 链下调研 与 词条文字。

| 规则 | 说明 / 反例 |
| --- | --- |
| 挖链是 X 高级搜索的**两个查询**：CA 走 `Latest`、`$TICKER` 走 `Top`，合并后按「名字贴合 ticker」排序。**搜索不走模型**（不消耗 token），任一引擎有结果即停止；没配 cookie 时整层静默失效，**不阻塞流程**（见 `CLAUDE.md` · 边界与待决）。 | 只发 CA 一个查询会遗漏：实测只有 ticker 查询能检索到某些官方号。 |
| 互证只读前 8 个候选页，`tier` 由页面本身判定；**bio 带 CA 才是 `own`**。站点链接先归一到根域再判。 | 高频发帖账号会把这 8 个名额占满，所以排序决定读取顺序；不归一的话，一个发射台的三个深链会被逐个读成 `none`。 |
| 读页面的素材有上限：正文合计 **15000 字符**，链接最多 **8 个**；官方 X 时间线另给 **15000 字符**（约最近 20 条，带时间戳与互动数）。`READABLE_SOCIALS` **含 TG** —— `t.me/<name>` 的公开预览页带频道名、成员数与最近几条帖子。 | 上限压到「够写一段」的量，模型就只能凭事实表写，叙事退化成数字堆砌。 |
| 空壳页面交浏览器画，账号页永远不画：静态 lane 不跑 JS，而 Arc 上的发射台官网多是 React 空壳，判定阈值 `identify.SHELL_WORDS`。渲染只在**已证明是空壳**时发生，且只有**候选官网**走这条路；X 与 TG 是例外（`NO_RENDER`）—— X 只向静态客户端提供 bio，浏览器看到的是登录墙。 | 实测几个 Meme 站静态页面只有 8–10 个词，连 CA 都检索不到，渲染后是几百个词且带 CA。曾经因此判成 `none`，卡片上显示的是第三方站。`networkidle` 与第三方渲染服务均已尝试并放弃（过慢，且会破坏 SPA 渲染）。 |

| 变量 | 作用 |
| --- | --- |
| `CH_X_AUTH_TOKEN` / `CH_X_CT0` / `CH_X_CLI` | X 搜索的会话 cookie 与承载客户端（只放在 `config/system.yaml`）。**会话是用时才读的**：保存新 cookie 后下次搜索即生效，无需重启（见 `api/app/api/v1/README.md` · 系统设置（本机接线））。**搜索不走模型，所以没有「搜索模型」这一项** |
