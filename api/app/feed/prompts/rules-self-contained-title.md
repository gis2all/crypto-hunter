
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：代币名 / 协议名 / 链名 / 项目名 / 交易所名 / 机构名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是代号 / 地址 / 没信息量的喊话（如 "gm"、"Day 1"、"new listing"、"重磅上线"）时，结合【来源】和正文把主体补进标题。
4. 补主体只能用【来源】或正文里真实出现的名字（代币符号、项目名、链名）。正文和来源都没点出具体名字时，用上位词（如"某 Solana 生态项目"）兜底，绝不凭行情常识编一个具体名字 / 代号 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析或教程标题，中文标题必须保留这个类型；不能因为正文谈到某个已经存在的项目或数据，就改写成"上线 / 暴涨 / 融资"。只有原标题明确宣布了上线、融资、被攻击或上架，中文标题才能使用对应动作。
   例：原标题 "How to read a bonding curve" → "如何读懂联合曲线"，不能写成 "某项目上线联合曲线"。
