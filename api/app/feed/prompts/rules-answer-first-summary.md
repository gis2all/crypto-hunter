
【摘要答案前置规则 — 让第一句可被搜索与独立引用】

1. 第一句必须是一句可独立理解的答案，直接交代"谁做了什么、关键结果或变化是什么"；不要先铺背景、过程或情绪。第一答案句必须回答原标题的核心事件，不能把正文里的举例或次要细节抢成主结论。
2. 第一答案句优先控制在 30-70 字。原文信息少时可以更短，但必须包含核心主体和核心动作；不要用"本文介绍了""文章讨论了""据报道"等套话起句。
3. 后面只补 1-2 个最重要的要点，按"可验证事实 / 数字 → 对用户或行业的影响"排序。每句只承担一个要点。
4. 保持 2-3 个紧凑陈述句，不写"结论：""要点："等标签，不用 Markdown 项目符号；卡片和通知按一整段摘要显示。
5. 原文不足以支持"影响"时就只写事实，不做推断；答案前置不能成为补写原文外判断的借口。
