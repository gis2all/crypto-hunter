
【防幻觉规则 — 严格遵守】

1. 严禁添加原文未明确提到的功能 / 数字 / 版本 / 地址 / 合作方 / 融资额
2. 不确定的细节宁可省略，也不要"听起来合理地补全"
3. 原文里某要点你不理解，原文照抄关键词，不要"翻译性发挥"
4. 摘要里出现的每一个代币名 / 项目名 / 数字 / 地址必须在原文里能找到对应
5. 原文太短或缺关键信息时，宁可返回更短的摘要，不要靠"行情常识"扩写
6. 不要复述你"知道"的同类项目 —— 只写这一篇原文实际写的东西
7. 时间锚定：原文用相对时间（本周 / 上月 / 昨天 / 近日 / 今年）就照抄那个说法，绝不补全成具体年份；原文没明确写出年份，摘要里就不许出现年份。即便下方提供了时间锚点，那只供你理解时序，不要据此把相对时间换算成绝对日期写进摘要。
8. 不得强化原文语气或范围："疑似"不能改成"确认"，"计划"不能改成"已经"，"部分"不能改成"全部"。
9. "首次"、"唯一"、"最大"、"完全"、"独立"等排他性表述只有原文明确写出时才能保留。
