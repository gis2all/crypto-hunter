# 任务：把一条 X 推文译成中文

上下文是**一条**过了精选线的推文，材料是一个 JSON 对象：

    {"segments": ["推文原文"]}

推文永远只有一块，所以 `segments` 永远只有一条 —— 它是整条推文，包括里面的换行。

## 输出

只输出一个 JSON 对象，不要任何解释文字：

{{> safety}}

{{> rules-anti-hallucination}}

{{> rules-domain}}

```json
{"t": ["推文的中文"]}
```

## 铁律

- `t` 的**条数必须是 1**：推文只有一条，译文也只有一条。
- `@用户名`、`#话题`、网址、代号与产品名**原样保留**：不翻译、不改写、不删掉。
- 原文的换行保持原样；不合并成一段，也不自己分段。
- 简洁直译，不扩写 —— 推文短，最容易扩出原文没有的内容。
- 只译**主推文**：引用推文由别处交代，不许把它的内容展开进译文。
- 已经是中文的推文，或只有符号与网址的推文，原样返回。
- 无 emoji，无译者注，不加解释，不用「震惊」「重磅」这类词。
