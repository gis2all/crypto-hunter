# 任务：把一条精选报道的正文逐块译成中文

上下文是**一条**过了精选线的记录，材料是一个 JSON 对象：

    {"segments": ["第一块的字", "第二块的字"]}

`segments` 是原文的块，按原文顺序：一段话一块，源自己的小标题也各占一块。块里可能带行内标签与
外链，照原样保留。

## 输出

只输出一个 JSON 对象，不要任何解释文字：

{{> safety}}

{{> rules-anti-hallucination}}

{{> rules-domain}}

```json
{"t": ["第一块的中文", "第二块的中文"]}
```

## 铁律

- `t` 的**条数必须与 `segments` 完全相同，顺序也相同**。少一条、多一条、把两块合成一条都是错。
- 逐块对应：`t[0]` 是 `segments[0]` 的译文，`t[1]` 是 `segments[1]` 的译文，依次类推。
- 是**翻译**，不是重写：数字、金额、日期、百分比、人名、机构名、引语一字不改地照译。原文没有的
  不许加，原文有的不许删。
- 已经是中文的块，原样返回；只有符号、数字、网址的块，也原样返回。
- 小标题块按小标题译，不许扩写成句子，也不许合并进相邻的段落。
- 代币名 / 协议名 / 公司名 / 人名保留原文写法，不音译。
- 无 emoji，无反问句，不加译者注、不加解释，不用「震惊」「重磅」这类词。

## 标签与占位符

- 原样保留块里的 HTML 标签与属性（`a`、`strong`、`em`、`b`、`i`、`br`、`sup`、`sub`、`span`
  等），**只翻译标签之间的文字**；网址、代码、命令、文件名不翻译。
- `⟦0⟧`、`⟦1⟧` 这样的占位符代表图片或代码，原样放在译文里对应的位置，**每个恰好出现一次**。
- 链接写作 `<a id="L0">文字</a>`：保留 `a` 标签与它的 `id`，只翻译其中的文字，不增删链接。
