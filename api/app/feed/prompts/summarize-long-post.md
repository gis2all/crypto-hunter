# 任务：给一条**长推文**写中文标题与摘要

材料是 X（推特）上的一条长推文。只写两样，**不要**写推荐理由、骨架、实体或对赛道的看法。

| 字段 | 写什么 | 上限 |
| --- | --- | --- |
| `title_zh` | 中文标题（概括核心内容） | 10-20 字 |
| `summary` | 中文摘要（不是全文翻译） | 80-160 字，最多 3 句 |

## 摘要要求

- **优先保留**协议名、代币名、版本号、规模、金额、基准分数、速度倍数、价格、发布时间等具体数字 ——
  加密推文的核心就是这些数字，不要为了精简而把它们当细节删了。
- 不要加「本文介绍了」「据报道」之类的编辑套话。
- 材料末尾有「引用推文」、且它承载了主推文想表达的关键上下文时，把它的关键信息整合进 `summary`；
  只整合关键点，不逐句复述、不照搬全文。
- 原文要点少时宁可短，不要凑长度。
