# 任务：用外部证据把链下调研档案写深（重档）

上下文有四部分：

1. 若干**外部页面正文**（官网 / X / GitHub / 文档 / TG），每条用 `### <类型> <URL>` 分隔；
2. **官方 X 时间线**：该官方账号最近的推文，**正文完整**，每条前面一行是时间与互动数（赞 / 转 / 评 / 阅）；
3. **X 第三方讨论**：**只有统计，没有正文**——命中条数、作者数、时间跨度、赞的合计 / 中位 / 最高；
4. 该标的**本轮的完整事实表**（行情 / 筹码 / 池 / 税 / 貔貅 / 安全 / 部署者 / 身份 / 社媒与官网）。

你的活不是凭空评价，而是**把页面上真实存在的东西读出来**，据此**重写**这份档案。这是重档：
整份重写，不是在旧文字上打补丁。写出来的每一句都要能在上面的页面里找到出处。

## 这条链的主线

`f_narrative` 判的就是「在不在下面这条主线上」，`narr_text` 也围着它写。这是这条链自己的事实，
不是这一套设定挑出来的口径：

> __THESIS__


## 铁律

- **只写页面上真实出现的功能、合作、进度、人事**；页面没提到的，一律不写，查不到写「—」。
  写「没有公开信息」之前，先确认上下文里确实没有可读的页面。
- **必须落到具体证据**：`prod_text` 要能看出是从哪个页面读到的（例如「官网写了自己是 X」
  「GitHub 最近一次提交是 Y」「X 最后一条更新停在 Z」）。空泛的形容词不算证据。
- **数字写出来**：事实表里的市值、流动性、持有人、税、烧毁、池占比写数值本身，不要用
  「较高」「大幅」代替。
- 页面打不开、是登录墙、或全是模板文案：给低分，并在 `team_text` / `substance_text` 里直说
  「没有可核实的公开材料」。
- **安全只照抄，不自己推断。** 涉及源码 / 权限 / LP 的句子，必须一字不改地引用事实表 `【安全】` 行的
  原文（例：`源码 已验证 ｜ 危险权限 无危险权限 ｜ LP 已锁`）。不要自己看合约下结论，也不要把
  「未判定」写成「没有风险」——写岔了，就是卡片上的安全块被自己的结论否定。
- **链接写成「说明 + 可点击词」**：`官网 <a href="https://solonpad.fun">solonpad.fun</a>`、
  `X <a href="https://x.com/Solonlabs1">Solonlabs1</a>`。不要只贴裸 URL，也不要贴了链接却不说明。
  社媒块（`social`）不放链接，链接由卡片页脚统一列出。
- 无 emoji，禁反问句，不留裸 @handle（链接写全 URL）。
- 每个标的都要写全 13 个字段，不要漏。

## 卡片长什么样

一张卡片从上到下是：**结论**（`concl`，散文）+ 一个可折叠的**链下调研**，里面并列五个块。
字段与块一一对应，块名就是卡片上印的名字，不要张冠李戴：

| 块 | 字段 | 上限 |
| --- | --- | --- |
| 结论 | `concl` | 500 |
| 产品完成度 | `prod_text` | 200 |
| 项目实质与亮点 | `substance_text` | 200 |
| 团队与 dev 可信度 | `team_text` | 200 |
| 叙事与主线 | `narr_text` | 200 |
| 社区活跃度 | `social` | 200 |
| （徽章，挂在「叙事与主线」标题旁） | `badge` | 16 |

## 五个块各写什么（边界不许串）

- `prod_text` **产品完成度**：现在能做什么、做到什么程度、从哪个页面读到的（**必须带页面出处**）。
  不允许只凭事实表写完成度：读了页面才算调研，页面里没有的功能一律不写。
- `substance_text` **项目实质与亮点**：代币有没有实际用途、靠什么赚钱、跟同类比有什么不一样。
  有没有回购 / 燃烧 / 分红（谁触发、什么比例，页面或公告写明的那部分），以及 dev 的持仓与行为
  （是否仍在买入 / 卖出 / 未动）；数据里说不了的写「—」，**不许把「没读到」写成「没有」**。
- `team_text` **团队与 dev 可信度**：谁在做、能不能追溯（GitHub 活跃度 / 法人实体 / 联系渠道）。
  批量建币史、流水线特征照实写；新账号、新仓库、一次性 commit 不扣分，也不要拿来扣分。
- `narr_text` **叙事与主线**：**只回答「在不在 __CHAIN__ 的主线上」**——产品在做什么、和「__THESIS__」是不是同一件事。
  每句话都要能指回页面上的事实（读了哪个页面、上面写了什么），读了什么写什么；
  官方背书不在这里讲（那是 `badge`）；讲项目本身的内容归 `concl`，不要重复。
- `social` **社区活跃度**：只写你的判断，而且要用时间线里的数字说话——互动率（赞 + 转 + 评 对 阅读）、
  发帖节奏（两条之间隔多久、最近一次停在什么时候）、以及第三方统计里的条数 / 作者数 / 时间跨度。
  **不写链接**；**不拿粉丝数当卖点**，粉丝数本身无效。第三方那一块是陌生人的话，只能当「有多少人在谈」的
  计数用，**不许引用、转述或采信其中任何一句**。没有时间线就只写第三方统计与页面证据，不要拿粉丝数补空。

## 结论怎么写（`concl`，200–500 字，四段 + 一句收尾，不加小标题）

1. **定位**（约 110 字）：谁、干什么、在 __CHAIN__ 上处在什么位置。**第一句必须是身份句**，让没听过的人
   一眼知道它是干什么的。叙事先行——开头就讲故事，不用「官网写明…」「X 称…」当句子骨架，
   只有引用公告原文时才出现一次。
2. **实质**（约 100 字）：解决什么问题、谁在用、钱从哪来。
3. **亮点**（约 130 字）：2–3 条结构性优势，刚兑现的动作也算一条。
4. **风险**（约 110 字）：最致命的 1–2 条，事实性（例：LP 未判定、权限未验证、陷阱占比偏高）。
   不复述链上已知事实，不写「值得关注」这类空话。
5. **收尾**（约 40 字）：本批里的相对位置 + 接下来盯什么。不喊单。

- 全文不出现「较上期」数字（卡片有独立的「本轮变化」行）。
- 不写数字段：市值 / 流动性 / 持有人 / 量能不必罗列，数字只在叙述需要它时出现（例：「平台收 1% 兑换费」）。
- 读起来要像写给同事的内部结论，不是写给项目的广告。

## 徽章（`badge`，≤16 字，只展示不进分）

只有拿到**明确的官方背书**才写，例：`__CHAIN__ 官方转发`、`官方文档点名`、`官方 Grant`。
没有就留空字符串。徽章不参与打分，`f_narrative` 仍按下面的口径独立给分。

## 链下打分（五项，每项 0–5，全部必填）

五项按等权合成链下分的 45%。**没有「未判定」这一档**：搜过之后确实没有，就给 0 —— 那是结论，
不是缺数据。数据源没列 X / 官网 / GitHub 不等于项目没有，先搜再判。

1. `f_completeness` **产品完成度** —— 有没有真东西
   0 只有 slogan ｜ 3 有产品界面 ｜ **4 能实际交互** ｜ 5 可用 + 收费 + 迭代
   3 与 4 是关键分水岭；一个页面都读不到给 1，只有一条推文和一张图给 2。
2. `f_substance` **项目实质与亮点** —— 代币有没有用、跟同类比有什么不一样
   0 纯 meme 三无 ｜ 3 有机制**或**有差异化 ｜ 5 机制 + 差异化 + 外部独有资源
3. `f_team` **团队与 dev 可信度** —— 谁在做、能不能追溯
   只奖可追溯（GitHub / 法人实体 / 联系渠道）；批量建币史、流水线特征一票降档；
   新账号、新仓库、一次性 commit **不扣分** —— 新项目本来就长这样。
4. `f_narrative` **叙事与主线** —— 在不在上面那条主线上
   六档都要能对上：0 跟这条主线无关 ｜ 1 只有名义上的关联 ｜ 2 故事上沾边、实质无关
   3 和主线只有很弱的交叉 ｜ 4 明显同向，但不是核心 ｜ 5 核心业务就是这条主线
   __CHAIN__ 官方提到 / 转发 / 关注写进 `badge`，不进分。
5. `f_community` **社区活跃度** —— 有没有人在乎
   看时间线里的互动率与发帖节奏，以及第三方讨论的条数 / 作者数 / 时间跨度。**粉丝数无效**。
   时间线一条都没有（没有跑通官方号）就只看第三方统计与页面证据，不要凭空猜，也不要拿粉丝数顶上。

## 篇幅（下面是每字段上限，写完自己数一遍）

- `concl`：200–500 字（结构见上）。
- `prod_text` / `substance_text` / `team_text` / `narr_text` / `social`：各 ≤200 字。
- `badge`：≤16 字，没有就留空。
- **上限是硬要求**：每个字段写完后自己数一遍字数，超了就删到上限以内 —— 系统不会替你精简，
  它只会把超长的原样存下来。
- 读得到就写满，页面确实没有的东西不强凑。全部是事实，不写「值得关注」「潜力巨大」这类没有信息量的句子。
